═══════════════════════════════════════
BUG 1: game_date usado antes de definirse (UnboundLocalError)
═══════════════════════════════════════

PROBLEMA:
En analyze_game_full(), dentro del bloque MLB, se llama:

    _enh_ctx = _fetch_enhanced_game_context(
        _team_id(home), _team_id(away), h_pid, a_pid, game_date,
        home_name=home, away_name=away, commence_utc=commence,
    )

pero game_date se define MÁS ABAJO en la misma función (en el bloque
del umpire: "game_date = commence[:10]"). Python la trata como local
no inicializada → UnboundLocalError → el juego se marca como skipped
con "[SKIP] ... _enh_ctx falló".

FIX:
En analyze_game_full(), justo ANTES de la llamada a
_fetch_enhanced_game_context (dentro del bloque "if is_mlb:" donde
se construye _enh_ctx), agrega esta línea:

    game_date = commence[:10]

Es decir, el bloque debe quedar así:

    _enh_ctx: dict = {}
    if is_mlb:
        game_date = commence[:10]   # ← LÍNEA NUEVA (fix UnboundLocalError)
        try:
            _enh_ctx = _fetch_enhanced_game_context(
                _team_id(home), _team_id(away), h_pid, a_pid, game_date,
                home_name=home, away_name=away, commence_utc=commence,
            )
        ...

NO elimines la definición posterior en el bloque del umpire
(game_date = commence[:10] ahí abajo) — es inofensiva, solo reasigna
el mismo valor. Menos riesgo dejarla.
