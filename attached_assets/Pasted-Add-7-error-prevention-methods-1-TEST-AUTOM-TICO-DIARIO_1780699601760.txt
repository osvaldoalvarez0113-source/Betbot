3. RANGO DE VALORES VÁLIDOS
━━━━━━━━━━━━━━━━━━━━
Before using ANY stat, validate range:

ERA: 1.50 - 8.00
  (outside range → reject, use null)
  
FIP: 1.50 - 8.00
  (outside range → reject)

OPS: 0.500 - 1.100
  (outside range → reject)

Bullpen ERA: 2.00 - 7.00
  (outside range → reject)

Win%: 0.20 - 0.80
  (outside range → reject)

RS/RA per game: 2.0 - 8.0
  (outside range → reject)
  (4.5/4.5 identical → reject as generic)

Goals per game (soccer): 0.3 - 3.5
  (outside range → reject)

ELO: 1200 - 2200
  (outside range → reject)

If rejected → remove from game_data
Never send invalid data to Claude.

7. MODO CONSERVADOR AUTOMÁTICO
━━━━━━━━━━━━━━━━━━━━
Before analyzing each game,
calculate data completeness score:

Score each available field:
✅ Pitcher name + ERA: +20 points
✅ FIP: +10 points
✅ Bullpen ERA verified: +15 points
✅ Home/away splits real: +15 points
✅ Umpire data: +10 points
✅ Wind/weather: +10 points
✅ Lineup confirmed: +10 points
✅ H2H data: +10 points

Total possible: 100 points

Thresholds:
80-100 points → análisis completo
   Normal confidence levels allowed

50-79 points → datos incompletos
   Max confidence: MEDIA
   Add: "⚠️ Análisis con datos 
   parciales — verificar antes 
   de apostar"

Below 50 points → skip game
   Don't analyze, don't alert
   Log: "Juego omitido por datos 
   insuficientes: [game]"

Show score in Claude data:
"data_quality_score": 73

Claude uses this to calibrate
confidence in its analysis.
